# Telemetry Platform

Розподілена мікросервісна IoT-платформа для реального моніторингу телеметрії та інтелектуального аналізу аномалій у системах резервного енергозабезпечення на базі моделей штучного інтелекту Google Gemini.

## Основна архітектура

Проєкт реалізовано за мікросервісним принципом у контейнеризованому середовищі:
* **Ingestion Service** — приймання телеметрії від IoT-обладнання через протокол MQTT (Eclipse Mosquitto).
* **ETL Pipeline** — потоковий конвеєр очищення, валідації та збагачення даних (Python, RabbitMQ).
* **Storage Tier** — комбіноване збереження даних: InfluxDB (часові ряди), Redis (гарячий оперативний кеш) та PostgreSQL (метадані та журнал подій).
* **LLM Service** — фоновий семантичний аналіз аномалій та генерація керуючих команд зворотного зв'язку за допомогою хмарного API Google Gemini (модель Gemini 1.5 Flash).
* **API Service & Dashboard** — веб-інтерфейс оператора на базі FastAPI (асинхронний REST API, веб-дашборд у реальному часі через WebSockets, інтелектуальний RAG-чат та безпека на базі Auth0).

## Швидкий запуск

### 1. Налаштування середовища
Створіть файл `.env` у корені проєкту (використовуючи за зразок `.env.example`) та додайте ваш унікальний ключ доступу до хмари Google:
```env
GEMINI_API_KEY=your_google_api_key_here
```

### 2. Запуск контейнерів
Запустіть весь стек мікросервісів однією командою:
```bash
docker compose up -d --build
```

## Доступ до сервісів платформи

* **Веб-інтерфейс оператора (Дашборд & Чат):** http://localhost:8000
* **Інтерактивна документація REST API (FastAPI Swagger):** http://localhost:8000/docs
* **Панель керування чергами RabbitMQ:** http://localhost:15672 (логін: `platform` / пароль з `.env`)
* **База даних часових рядів InfluxDB UI:** http://localhost:8086 (користувач: `admin`)
